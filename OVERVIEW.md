Markdown Outline opens `.md` and `.markdown` files in a reading view with a heading outline beside the document, like the outline sidebar in Typora.

Choose **Markdown with outline** when Paseo asks which viewer to use for a Markdown file, or pick it later from **Open with…** in the tab menu or in **Settings > Files**.

## What you can do

- Click a heading in the outline to scroll the document to it.
- See the heading you are reading highlighted as you scroll. Long outlines follow along.
- Collapse and expand sections like folders in a file tree, or collapse all at once.
- Move the outline to the left or right, or hide it, from the buttons in its header.
- On phones and narrow windows, open the outline from its button; picking a heading closes it.

Inline code in headings keeps its code styling in the outline. YAML front matter shows as a table at the top. Relative links and images resolve from the file's own folder.

## Settings

Under **Settings > Plugins > Markdown Outline**: outline side, outline width (narrow, normal or wide), and whether the outline shows when a file opens. These choices are stored on each device.

## Limits

The view is read-only. Use **Open with…** to switch to Paseo's Markdown panel to edit the source. Headings inside block quotes and list items do not appear in the outline.

The plugin only reads the open file through Paseo. It sends nothing to agents or other services.
